# Nguyen Dang Minh Quan Portfolio

This is a static English portfolio built with HTML, CSS, and JavaScript. It is based on `Nguyen_Dang_Minh_Quan_CV_UIT.pdf` and includes the provided GitHub and LinkedIn links.

## Before submitting

1. Open `index.html` in a browser and check the layout.
2. Add direct project repository/demo links if the repositories are public.
3. Keep `Nguyen_Dang_Minh_Quan_CV_UIT.pdf` in the same folder so the Download CV button works.
4. Deploy the folder to GitHub Pages, Vercel, or Netlify to get a public URL.

## Quick deploy with GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload every file in this folder to the repository.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Choose branch `main`, folder `/root`, then click `Save`.
6. Wait 1-2 minutes. GitHub will provide a URL like:

```text
https://your-github-username.github.io/portfolio/
```

Submit that public URL in the portfolio form.
